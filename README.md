# مدیریت استاپ‌لاس حساب LiteFinance — شماره حساب 918850

این ریپو دو اسکریپت پایتون دارد که به ترمینال **MT5 لایت‌فایننس** شما وصل می‌شوند و فقط روی **پوزیشن‌های بازِ اکسپرت (Javier / تریدینگ‌ویو)** حد ضرر (SL)، حد سود (TP) و تریلینگ استاپ را مدیریت می‌کنند:

- 🔒 **هیچ‌وقت پوزیشن جدید باز نمی‌کنند** — فقط SL/TP پوزیشن‌های موجود را تنظیم یا جابه‌جا می‌کنند.
- 🔒 فقط به حساب کانفیگ‌شده وصل می‌شوند: **لاگین `918850`، سرور `LiteFinance-MT5-Live`، حالت live** — اگر ترمینال به هر حساب/سرور دیگری وصل باشد، اسکریپت بلافاصله متوقف می‌شود.
- 🔒 فقط پوزیشن‌های نماد `XAUUSD_i` با مجیک‌نامبر `2021` (پوزیشن‌هایی که خودِ اکسپرت باز کرده) را دست می‌زنند.

## فایل‌ها

| فایل | کار |
|---|---|
| `javier_stops_guard.py` | برای پوزیشن‌هایی که SL/TP ندارند، بر اساس ATR همان لحظه ورود، حد ضرر و حد سود تنظیم می‌کند (فاصله SL = `1.5 × ATR`، فاصله TP = `2 × ATR`، با سقف ضرر مالی `max_loss_money`) |
| `javier_trailing.py` | تریلینگ استاپ: SL را دنبال قیمت حرکت می‌دهد و سود را قفل می‌کند. TP موجود را دست نمی‌زند |
| `javier_live.json` | تنظیمات اسکریپت اول (حساب، سرور، نماد، مجیک، پارامترهای ریسک) |
| `javier_trailing_live.json` | تنظیمات اسکریپت تریلینگ |

## پیش‌نیازها (روی همان ویندوز/VPS که ترمینال MT5 روی آن باز است)

1. ترمینال MT5 لایت‌فایننس **در حال اجرا** و لاگین با حساب `918850` باشد (همان ترمینالی که اکسپرت روی آن است).
2. دکمه **Algo Trading** ترمینال روشن باشد (برای اینکه پایتون بتواند سفارش SL/TP بفرستد).
3. پایتون ۶۴ بیتی نصب باشد، سپس:

```bash
pip install -r requirements.txt
```

4. مسیر `terminal_path` را در هر دو فایل JSON با محل نصب واقعی `terminal64.exe` روی سیستم خودتان چک کنید (الان: `C:\Program Files\LiteFinance MT5 Terminal\terminal64.exe`).

> ⚠️ پکیج `MetaTrader5` فقط روی ویندوز کار می‌کند و اسکریپت باید روی **همان سیستم/سروری** اجرا شود که ترمینال MT5 روی آن باز است؛ از راه دور وصل نمی‌شود.

## گام ۱ — بررسی نماد و مجیک‌نامبر (یک‌بار اجرا کنید)

اگر مطمئن نیستید نماد پوزیشن‌ها دقیقاً `XAUUSD_i` است و مجیک آنها `2021` است، وقتی اکسپرت پوزیشن باز دارد این را اجرا کنید:

```bash
python -c "import MetaTrader5 as mt5; mt5.initialize(r'C:\Program Files\LiteFinance MT5 Terminal\terminal64.exe'); [print(p.ticket, p.symbol, 'magic=', p.magic, p.comment) for p in mt5.positions_get()]; mt5.shutdown()"
```

هر چه در ستون `symbol` و `magic` دیدید، در دو فایل JSON وارد کنید. اگر مجیک یا نماد نخواند، اسکریپت‌ها آن پوزیشن‌ها را نادیده می‌گیرند (هیچ خطری ندارد، فقط کاری انجام نمی‌شود).

## گام ۲ — تست بدون ریسک (Dry Run)

هر دو اسکریپت **به‌صورت پیش‌فرض فقط گزارش می‌دهند و هیچ تغییری نمی‌دهند**:

```bash
python javier_stops_guard.py
python javier_trailing.py
```

در این حالت در کنسول و فایل‌های `javier_python_guard.log` و `javier_trailing.log` می‌بینید که چه SL/TP‌ای تنظیم می‌کرد (عبارت `DRY RUN` و `PREVIEW`). وقتی خروجی را پسندیدید، به گام ۳ بروید.

## گام ۳ — اجرای واقعی

هر اسکریپت را در یک پنجره جداگانه CMD/PowerShell اجرا و **باز نگه دارید**:

```bash
python javier_stops_guard.py --apply
python javier_trailing.py --apply
```

- این دو با هم سازگارند: گاردِ استاپ فقط پوزیشن‌هایی را دست می‌زند که هنوز SL و TP ندارند؛ تریلینگ بعد از آن SL را دنبال قیمت می‌برد.
- اگر Algo Trading خاموش باشد، اسکریپت در حالت `READY ... waiting for Algo Trading permission` منتظر می‌ماند و به‌محض روشن شدن شما شروع به کار می‌کند.
- اگر اتصال قطع شود، خودش صبر می‌کند و بعد از وصل شدن دوباره چک می‌کند.

## پارامترها

### `javier_live.json` (استاپ گارد)

| کلید | مقدار فعلی | معنی |
|---|---|---|
| `account` / `server` / `trade_mode` | `918850` / `LiteFinance-MT5-Live` / `live` | حساب مقید شده — تغییر ندهید مگر حساب عوض شود |
| `symbol` / `magic` | `XAUUSD_i` / `2021` | فقط پوزیشن‌های این نماد و این اکسپرت مدیریت می‌شوند |
| `atr_period` | `14` | دوره ATR روی کندل M1 قبل از ورود |
| `atr_stop_multiple` | `1.5` | فاصله SL = ۱.۵ برابر ATR |
| `atr_target_multiple` | `2.0` | فاصله TP = ۲ برابر ATR |
| `max_loss_money` | `50` | **سقف ضرر هر پوزیشن به ارز حساب (دلار)** — اگر SLِ ATR بیشتر از این عدد ضرر بدهد، SL به این سقف محدود می‌شود. مطابق ریسک خودتان تنظیم کنید |
| `interval_seconds` | `5` | فاصله بررسی پوزیشن‌های جدید |

### `javier_trailing_live.json` (تریلینگ)

| کلید | مقدار فعلی | معنی |
|---|---|---|
| `distance_points` | `10` | فاصله SL از قیمت فعلی (به point) |
| `lock_points` | `5` | حداقل سودی که باید قفل شود تا SL حرکت کند (به point) |
| `interval_seconds` | `0.1` | سرعت بررسی قیمت |

> ⚠️ **دقت روی واحد پوینت طلا:** اگر point نماد طلا `0.01` باشد، `distance_points=10` یعنی SL فقط **۱۰ سنت (0.10 دلار)** پشت قیمت می‌ماند — برای طلا بسیار تنگ است و احتمالاً زود می‌خورد. اگر فاصله منطقی‌تری می‌خواهید مثلاً ۱.۵ دلار پشت قیمت، مقدار را `150` بگذارید (و `lock_points` را متناسب، مثل `50`). این اعداد را حتماً خودتان چک کنید.

## نکات ایمنی

- اسکریپت‌ها قبل از هر نوشتن، دوباره حساب و پوزیشن را چک می‌کنند (`order_check` قبل از `order_send` و تأیید بعد از ارسال).
- اگر حساب/سرور/حالتِ ترمینال با کانفیگ نخواند، اسکریپت همان‌جا می‌ایستد و دستور نمی‌فرستد.
- این یک **حساب واقعی (Live)** است — قبل از `--apply` حتماً خروجی Dry Run را ببینید و پارامترهای ریسک (`max_loss_money`، فاصله‌های پوینت) را با سبک معامله خودتان تنظیم کنید.
